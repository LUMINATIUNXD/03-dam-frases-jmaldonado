# 03-dam-frases-jmaldonado

Práctica **App Frases** desarrollada con Flutter.

## Avance 1: pantalla principal

La aplicación muestra **Mis frases (0)**, un mensaje de estado vacío y el botón **+**. Esta entrega inicial reproduce la primera pantalla de la práctica; el formulario y la base de datos SQLite se integrarán en los siguientes avances.

## Ejecutar en Windows

Este repositorio incluye el código fuente inicial. Para crear la estructura estándar de Android en una copia recién clonada, teniendo Flutter instalado:

```powershell
flutter create --project-name=frases_app --platforms=android .
flutter pub get
flutter devices
flutter run
```

Abre el proyecto en VS Code y selecciona un celular Android conectado o un emulador configurado.
